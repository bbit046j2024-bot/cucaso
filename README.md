# CUCASO UI Prototype

A responsive front-end prototype for the CUCASO public website.

## Files
- index.html — public homepage
- styles.css — responsive design system and page styles
- script.js — mobile navigation and demo rally countdown

## Design direction
- Navy / royal blue primary
- Warm gold accent
- Ocean teal secondary
- Off-white sections
- Poppins headings
- Inter body/UI text
- Rounded cards and accessible contrast
- Mobile-first responsive layout

## PRD alignment
The prototype reflects the public website requirements:
identity/mission, member chapters, rally information, gallery, leadership, and calls to action for chapter registration and login.

This is a front-end prototype. Production authentication, database, Council approval, attendee registration, cost calculation, invoicing, Daraja payments, audit logging, and role-based permissions should be implemented in the application backend.
